# 隐私与能力边界

## 数据何时离开本机

v0.5.0 默认本地优先。案例 A、案例 C、审核知识校验、题目导入、导出和学习记录不需要云端服务。

只有你明确运行配置了 DeepSeek 的案例 B 或相应云端命令时，题目与生成所需的上下文才会发往 DeepSeek。请在发送前删除或替换：

- 姓名、学号、邮箱、电话和其他身份信息；
- API Key、访问令牌和内部地址；
- 私人 PPTX、受限教材、未公开试卷及未获授权的原文；
- 不应交给第三方处理的学校或课程数据。

云端请求可能产生费用。网络错误、限流或服务异常导致的重试也可能再次计费；请自行检查供应商价格、余额、日志保留政策和账户限额。

## 本地文件也需要保护

本地配置、命令历史、导出文件、学习记录和终端截图都可能包含敏感内容。Key 应通过 `PHYSICS_AGENT_CHAT_API_KEY` 环境变量或未提交的本地配置注入，不要写入题目、公开日志或 Git。共享机器上使用后请清理环境变量与不再需要的敏感文件。

## 能力边界

0.5.0 是仅面向 Linux/WSL 的 GitHub Pre-release。Windows 用户需通过 WSL 使用；学生不需要 Codex。

- `chat` 是没有物理一致性与来源发布门禁的原始通路，不代表通用可靠的大学物理解题器。
- 面向学生的受限入口是 `teach`；完整解答只覆盖当前力学白名单，不代表完整课程。
- M3 草稿知识不能用于教学，第八版教材映射仍待完成；没有本地模型时不能声称完整离线教学。
- 当前不提供自动评分、整卷批改、图像题处理、动画、Web UI 或完整章节覆盖。
- 云端验证只覆盖发布说明列出的固定案例，不能外推到任意题型。
- 模型输出可能出现概念、符号、单位或来源错误；完整解答也必须人工复核。

## 许可边界

- 原创代码采用 MIT License，版权人余杰（2026）。
- 审核知识包采用 CC BY-SA 4.0；再分发改编内容时应遵守署名与相同方式共享要求。
- 第三方依赖与材料各自遵循其许可证；以发布包中的 `NOTICE` 和 `THIRD_PARTY_NOTICES` 为准。
- 私人 PPTX、受限教材和未审核草稿不属于公开发布内容。

问题请提交到 [GitHub Issues](https://github.com/amazingand/university-physics-agent/issues)。Issue 默认公开，请勿提交 API Key、学生信息、私人教材、完整请求/响应或其他敏感数据。
